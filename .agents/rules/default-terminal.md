# Terminal Rule

This project uses Zsh as the default terminal shell. All terminal commands must use Zsh.

- Use Zsh instead of Bash or any other terminal shell
- Use Zsh for all terminal commands
- Use Zsh for all package management operations
- Use Zsh for all build operations
- Use Zsh for all test operations
- Use Zsh for all deployment operations
- Use Zsh for all documentation operations
- Use Zsh for all script operations
- Use Zsh for all example operations

Zsh configurations should use Zsh syntax instead of Bash syntax.

Keep Zsh configurations in .zshrc file.

Keep Zsh configurations organized and documented.

Keep zsh alive and prevent WSL timeouts or disconnections.
