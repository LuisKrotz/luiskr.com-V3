decimal-round function

@function decimal-round($number, $digits: 0, $mode: round) {

Rounds a number to N decimal digits using the given rounding mode. `round`/`floor` wrap in calc() so the result stays a math expression Sass can still compose; `ceil` returns a plain number (Sass has no native CSS ceil() at this pinned Sass version). Non-number inputs warn and pass through unchanged instead of failing the whole compile — a typo in one call site shouldn't kill the build.

Parameters

  • $number Number — Value to round.
  • $digits Number default: 0 — Decimal places to keep (must be unitless).
  • $mode String default: round — `round`, `ceil`, or `floor`.

Returns

Number The rounded value (or the input when invalid).

to-rem function

@function to-rem($value) {

Converts a px (or unitless px-meaning) number to rem at the 16px root. The px unit is stripped first so `to-rem(16px)` and `to-rem(16)` both yield 1rem — Fibonacci $space-* tokens are declared unitless.

Parameters

  • $value Number — px length or unitless px count.

Returns

String A `rem`-suffixed value rounded to 3 decimals.

grid-steps mixin

@mixin grid-steps {

Emits one `min-width: (step−1)px` media query per `$grid-steps` entry. Steps ≤ 272 are skipped — the watch viewport is the base (un-queried) layout. Keeping a single iteration point guarantees %MAXAREA gutters and the debug overlay can never drift apart.

@content Receives `($step, $gap, $cols)` per breakpoint.

focus-ring-scope mixin

@mixin focus-ring-scope {

Emits `:focus-visible` rules for every tabbable element type in the current scope — component sheets pull this in because document-level focus rules never pierce shadow DOM. `[tabindex='-1']` is excluded: those are programmatically-focused containers, not controls.
